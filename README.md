# Translate PDF

Translate PDF is a Python-based tool for extracting text from PDF files, translating it into different languages, and saving the translations into a new document.

## Features
- Extract text from PDF files.
- Translate text using an online translation API.
- Save translated text into a specified format.

## Requirements
- Python 3.7 or above
- See `requirements.txt` for dependencies.
